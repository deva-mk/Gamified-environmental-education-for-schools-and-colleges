# EcoChronicles

## Project Overview

EcoChronicles is an interactive web-based educational platform designed to promote environmental awareness among students through engaging activities, quizzes, and progress tracking. The system provides separate interfaces for students and teachers, enabling effective learning and performance monitoring.

---

## Problem Statement

Many students have limited awareness of environmental issues and sustainable practices. Traditional teaching methods may not always provide an engaging learning experience. EcoChronicles addresses this challenge by offering an interactive digital platform that encourages students to learn about environmental conservation through activities and assessments.

---

## Project Objectives

- Promote environmental awareness among students.
- Provide an interactive learning experience through quizzes and activities.
- Track student performance and learning progress.
- Enable teachers to monitor student participation and scores.
- Store and manage data using Firebase.
